# Chase Da Goop VR work area

This directory is a temporary, isolated staging area for the first native VR implementation.

The intended long-term boundary is a separate `goop-fishing-vr` repository. The GitHub integration available for this task can create branches and commits in existing repositories but does not expose repository creation. Until that repository exists, all VR work stays on the dedicated `vr/m1-unity-foundation` branch and never enters the browser game's mainline.

## Project order

1. Goop Fishing VR — Meta Quest 3S.
2. Hollow Reach VR — reuse only proven, generic VR foundation components.

See [Goop Fishing VR project](./GoopFishingVR/README.md).
